Descripción

Desarrollo de los sistemas de Interfaz de Usuario (UI) y de Onboarding (Tutorial) para un videojuego 3D de Tower Defense con mecánicas de fusión (estilo 2048). El proyecto integra un menú principal escalable, un HUD principal modular (GameHUD) con gestión dinámica de recursos y habilidades, y un nivel de tutorial interactivo diseñado para enseñar las mecánicas centrales de forma inmersiva y a prueba de frustraciones, utilizando un sistema visual de resaltado ("Spotlight") y pausas tácticas.
